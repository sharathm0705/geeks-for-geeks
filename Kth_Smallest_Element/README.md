# Kth Smallest Element

## Problem Statement
Given an array arr[] and an integer k where k is smaller than the size of the array, the task is to find the kth smallest element in the given array.

## Examples
**Example 1:**
```text
Input: arr = [7, 10, 4, 3, 20, 15], k = 3
Output: 7
```

## Constraints
```text
1 <= arr.size() <= 10^5
```
