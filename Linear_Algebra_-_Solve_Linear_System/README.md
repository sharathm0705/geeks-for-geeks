# Linear Algebra - Solve Linear System

## Problem Statement
Given a coefficient matrix a and a constant vector b, solve the system of linear equations represented by: a⋅x = b, where a is a 2-dimensional NumPy array, b is a 1-dimensional NumPy array, and x is the vector of unknown variables. Return the solution vector x.

## Examples
**Example 1:**
```text
Input: a = np.array([[3, 2],[1, 4]]), b = np.array([5, 6])
Output: array([0.8, 1.3])
Explanation: Solving the system of equations 3x + 2y = 5 and x + 4y = 6 gives x = 0.8 and y = 1.3
```

**Example 2:**
```text
Input: a = np.array([[2, 1],[5, 3]]), b = np.array([3, 7])
Output: array([2., -1.])
Explanation: Solving the system of equations 2x + y = 3 and 5x + 3y = 7 gives x = 2 and y = −1.
```
