# Missing in Array

## Problem Statement
Given an array arr[] of size n - 1 that contains distinct integers in the range from 1 to n (inclusive). Your task is to identify and return the missing element.

## Constraints
1 <= n <= 10^5, 1 <= arr[i] <= n

## Examples
Input: n = 5, arr[] = [1, 2, 3, 5]
Output: 4
