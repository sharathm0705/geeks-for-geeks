# Array Leaders

## Problem Statement
Given an integer array arr, find the leaders in the array. An element is a leader if it is greater than or equal to all the elements to its right side.

## Examples
**Example 1:**
```text
Input: arr = [16, 17, 4, 3, 5, 2]
Output: [17, 5, 2]
Explanation: 17 is greater than all elements to its right. 5 and 2 are also leaders.
```

## Constraints
```text
1 <= arr.size() <= 10^6
```
